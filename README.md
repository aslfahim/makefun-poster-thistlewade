THISTLEWADE — a travel poster for a marsh town built on stilts, where the
lilies grow large enough to moor a boat to. One Node program paints it from
raw pixels: a gold-green dawn, bands of mist, stilt houses with lantern
light along a walkway, a heron in the shallows, and giant lily pads with a
single pink bloom in the foreground water. The town's name is set in
hand-drawn stroke letters across the sky. It writes one PNG to
/output/entry.png.

## Run it

```sh
node main.ts
```
